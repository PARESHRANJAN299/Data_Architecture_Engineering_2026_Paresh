# AI Chatbot Hybrid Data Platform

This project will contain the end-to-end hybrid architecture combining AWS infrastructure and Databricks Lakehouse capabilities.

## Planned scope

- AWS streaming and storage infrastructure
- Databricks ingestion and transformation
- Delta Lake Bronze, Silver, and Gold layers
- Unity Catalog governance
- AWS security and networking
- AI and machine-learning serving
- BI and analytics serving
- Deep-learning and R&D workloads
- Monitoring, reliability, disaster recovery, and FinOps

## Status

Planned after completion of the AWS-only and Databricks-only portfolio projects.
